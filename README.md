# Dev Stack

Dev Stack is a responsive React website for exploring development technologies and creating a personal technology stack.

## Features

- Responsive Navbar
- Hero Section
- Technology Cards
- Technology Icons
- Add to Stack
- Remove Technology
- Remove All
- Duplicate Prevention
- Toast Notifications
- Loading State
- Dark/Light Theme
- Responsive Design

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- React Icons
- React Toastify

## How to Run

```bash
npm install
npm run dev
